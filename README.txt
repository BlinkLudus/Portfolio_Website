LEVEL DESIGN PORTFOLIO — QUICK START

1. Open index.html in a browser (or VS Code Live Server).
2. Edit project titles, text, cover paths, image galleries, and video links in js/projects.js.
3. Add your actual media files to images/stealth/, images/plurality/, images/godot/, and videos/.
4. For an image gallery item, use: { src: 'images/stealth/floorplan.png', caption: 'Annotated floor plan' }
5. For video, set video: 'videos/stealth.mp4' or use a YouTube embed URL such as https://www.youtube.com/embed/VIDEO_ID.
6. Change coverPosition: 'center 50%' to adjust cropping (0% top, 100% bottom).
7. Update the email in index.html and add cv.pdf if you want the CV button to work.
8. Publish the entire folder (not just index.html) to GitHub Pages or Netlify.

Missing cover images intentionally display a labelled placeholder until you add your files.
